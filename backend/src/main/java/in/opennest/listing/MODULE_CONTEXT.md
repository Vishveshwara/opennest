The retry worker removes known final objects and waits out signed staging URLs.

- Limits: 20 retained/5 published listings per owner; 20 images/listing; 60 reservations/rolling 24h; 10-minute PUT/5-minute GET URLs. Browser sources <=40 MB become opaque lossy AVIF locally, longest side <=2048, soft target 1 MB and no product output byte cap. Completion validates the pinned writer's single-item metadata-free container and one AV1 decode, preserving bytes and attaching a distinct final object idempotently. Legacy JPEG/PNG/WebP validators and saved photos remain supported.
- Separate private primary/sandbox R2 buckets/credentials; disabled storage fails upload operations with 503, no runtime fake fallback. Hourly cleanup removes old staging/orphan finals, preserves attached objects/drafts, and retains rate-accounting rows seven days.
